## 🎨 Design Philosophy — Neo-Brutalism

This site embraces the bold, playful, and unapologetic aesthetics of **Neo-Brutalism**:

- **Physical Button Physics**: Elements feature physical depression on active press (`transform: translate(2px, 2px)` with shadow snapping from `5px` to `1px`).
- **Hard-Edge Offset Shadows**: Zero blurred shadows (`box-shadow: 5px 5px 0px #000000`).
- **Dual Visual Modes**:
  - 🌙 **Cyber Dark Synth** (Default): Inky slate canvas (`#0e1017`) with electric Canary Yellow (`#FFE600`) and Cyber Cyan (`#38BDF8`) accents.
  - ☀️ **Classic Paper Canvas** (Light Mode): Warm parchment background (`#FFFDF0`) with stark black ink borders (`3px solid #000`) and highlighter sticker badges.
- **Retro OS Window Bars**: Dossier cards feature vintage macOS/OS9 window dots `[ ● ● ● ]` with system identifiers (`AFIF_PORTFOLIO.EXE`, `TASKFLOW.APP`, `LIVE_CAMPUS_OPS.SYS`).
- **Live Marquee Ticker**: Continuous horizontal ticker streaming real-time status and core strengths.
- **Zero Bloat / Pure Web Standards**: **0 npm packages**, **0 bundler configs**. Fast initial render, maximum accessibility, and pure web craftsmanship.
